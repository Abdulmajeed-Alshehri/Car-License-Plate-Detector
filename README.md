# Vehicle License Plate Detection using YOLOv8 🔥

 ## Project Overview
This project focuses on identifying vehicles and detecting their license plates in real-time. It utilizes the **YOLOv8 (Nano)** architecture for its balance between speed and accuracy, making it ideal for deployment on edge devices.

## Features
*   **Vehicle Detection:** Detects cars, trucks, and motorcycles.
*   **License Plate Localization:** Specifically trained to locate license plates under various lighting conditions.
*   **High Performance:** Optimized using the YOLOv8n (Nano) model.

## Tech Stack
*   **Framework:** Ultralytics YOLOv8
*   **Language:** Python
*   **Libraries:** OpenCV
*   **Training Platform:** Roboflow (Dataset management) , Kaggle (Train the model)
